## FastAPI Assignment 3

This project is a simple FastAPI application created as part of the February 2026 Internship Task.

The API manages a basic product inventory system and performs CRUD operations such as adding, viewing, updating, and deleting products.

## Features

* Add new products using POST
* View all products using GET
* Update product details using PUT
* Delete products using DELETE
* Inventory audit endpoint
* Category discount feature

## Code Explanation

The application is implemented in **main.py** using the FastAPI framework.
It stores product data in a list and provides different API endpoints to perform operations on the products.

Each endpoint handles a specific task such as creating a product, updating stock, deleting items, and generating an inventory report.
